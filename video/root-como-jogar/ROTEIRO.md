# Como jogar Root — roteiro narrado (~45 s)

**Fórmula** (a mesma dos tutoriais curtos que mais performam, ex.: @tiktokboardgames, 3–5 mi de views):
gancho comparativo com o nome do jogo → objetivo → como cada um joga → o turno → "parece simples, até…" → chamada.
**Fonte de todos os fatos:** tutorial publicado em eliteboardgamers.com.br/como-jogar/root/ (manual Meeple BR e Leis de Root).

| # | Fala | Tela |
|---|---|---|
| 1 | Este jogo de guerra fofo, em que cada jogador joga um jogo diferente, é Root. | Caixa oficial (MeepleBR) entra; título |
| 2 | Seu objetivo é chegar primeiro a trinta pontos de vitória. | Trilha de pontos 0 → 30 |
| 3 | Os Marqueses vivem de madeira: serrarias pagam construções, e construções dão pontos. | Facção laranja; madeira → construção → +PV |
| 4 | As Rapinas pontuam com ninhos, mas precisam cumprir o Decreto inteiro, ou caem em tumulto. | Facção azul; fila de ordens que racha |
| 5 | A Aliança espalha simpatia até se revoltar. | Facção verde; marcadores se espalhando, revolta |
| 6 | E o Malandro, sozinho, explora ruínas e cumpre tarefas. | Peão solitário; itens |
| 7 | Todo turno tem Amanhecer, Dia e Anoitecer. | Três faixas de luz |
| 8 | Para mover, você precisa governar a clareira de saída ou a de chegada. | Duas clareiras, seta |
| 9 | Parece simples, até a batalha: o atacante causa o dado maior, e o defensor, o menor. | Dois dados 0–3 rolam |
| 10 | O passo a passo completo, com exercícios, está no link da bio. | Cartela final |

## De onde vêm os roteiros dos vídeos que performam
Pesquisa no Virlo (biblioteca de vídeos analisados, board game + "how to play"): os tutoriais curtos que mais
performam, como os do @tiktokboardgames (1,3 mi de seguidores; Stax 5,7 mi de views, Slip It In 3,2 mi),
são o **manual do jogo condensado numa fórmula fixa**, lida em voz over em cima das peças na mesa.
Parte deles é patrocinada (#sponsored): a editora fornece os pontos principais.
Transcrições lidas: Stax (youtube.com/shorts/EmsNLDg2B-s), Slip It In (youtube.com/shorts/KiC8Fzo_LUc),
