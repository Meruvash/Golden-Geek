# O Assalto do Wan, Parte 2 (modelo v3). Aguardando aprovação

Versão escrita para a vitória de SOCAR; as trocas para ATIRAR estão no fim. Quadrado 1080x1080, ~105 s.
Regras usadas (resenha colt-express): soco derruba o saque e empurra para outro vagão; tiro põe bala inútil no baralho;
a maleta é guardada pelo xerife; no teto anda até 3 vagões mas fica mais exposto aos tiros; bônus para quem mais atirou;
regras de 2 páginas (Board Game Quest), 30–40 min, 2–6 jogadores.
